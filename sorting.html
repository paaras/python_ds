Selection sort

Selection sort sorts a list from left to right by picking the smallest value each time

  1. Find the smallest value
  2. Swap it into the first position
  3. Find the smallest value that's left and swap it into the second position
  4. Keep going until the whole list is sorted

  • i is the position we're filling
  • j scans the values after i

  • O(n²) time, since it makes n - 1 comparisons, then n - 2, and so on, even if the list is already sorted
  • O(1) space, since it swaps inside the list

Bubble sort

Bubble sort compares neighbors and swaps them if they're out of order

  1. Compare the first two values, and swap them if the left value is bigger
  2. Move to the next pair and do the same, all the way to the end
  3. The largest value is now at the end, so repeat on the rest of the list

Merging two sorted lists

Merging combines two sorted lists into a single sorted list, and it's the main step in merge sort

  1. Compare the first value left in each list
  2. Move the smaller value to the result
  3. Repeat until a list runs out, then move over the rest of the other list
  • O(n) time and O(n) space, since every value is copied once into a new list

Merge sort

A list with a single value is already sorted, so merge sort splits the list down to single values and merges them back together

  1. Split the list in half
  2. Keep splitting until every piece has a single value
  3. Merge the pieces in pairs
  4. Keep merging until the whole list is back together
  • O(n log n) time, since halving gives log n levels (like binary search) and each level merges all n values
  • O(n) space, since merging builds new lists

Merge sort: code

  • A list with 0 or 1 items is already sorted, so that's the base case
  • Otherwise split at middle and call merge_sort on each half

Quicksort

  1. Pick a value to be the pivot (we use the last value)
  2. Move smaller values to its left and bigger values to its right
  3. The pivot is now in its final position
  4. Repeat on each side

It works like a binary search tree, with each pivot as a root
