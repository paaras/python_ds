What is a stack

  • A stack is a collection where items are added and removed in one place only, called the top
  • The last item added is the first item removed
  • This rule is called LIFO: Last In, First Out
  • Think of a stack of plates, you put a new plate on top, and you take a plate from the top

Stack operations

  • push(item): add an item to the top
  • pop(): remove the top item and return it
  • peek(): return the top item without removing it

Stack using a list: where is the top

  • The top of the stack could be index 0 of the list or the last index of the list
  • Adding or removing at the last index: no other items move
  • Adding or removing at index 0: every other item has to shift one position
  • So the top of the stack is the last index of the list

Stack using a linked list: where is the top






    

  • We can reach the head of a linked list directly, reaching the last node means walking through every node
    • 

  • So the head is the top
    • 

  • push: create a new node, point it at the current head, make it the new head
    • 

  • pop: save the head's value, move head to the next node, return the value
    • 

  • peek: return the head's value
    •

  • A list has a fixed amount of space set aside, when it is full, Python moves the list to a bigger block of memory and copies every item over
    • 

  • That copy is O(n), but it happens rarely, so on average append is O(1)
    • 

  • A linked list never copies, every push creates one new node
    • 























Stack space complexity






    

  • Both versions use O(n) space for n items
    • 

  • A list uses one slot per item, plus some spare slots left over from growing
    • 

  • A linked list uses one node per item, each node holds the item and a next pointer
    • 

  • So a linked list uses more memory per item, but in both cases memory grows in proportion to n
    •

What is a queue






    

  • A queue is a collection where items are added at the back and removed from the front
    • 

  • The first item added is the first item removed
    • 

  • This rule is called FIFO: First In, First Out
    • 

  • Think of people waiting in line, new people join at the back, and the person at the front is served first
    • 























Queue operations






    

  • enqueue(item): add an item to the back
    • 

  • dequeue(): remove the front item and return it
    • 

  • peek(): return the front item without removing it
    •

Queue using a list: the problem






    

  • A queue adds on one side and removes from the other, so one of them has to be index 0
    • 

  • Option A: enqueue with append(), dequeue with pop(0), dequeue shifts every item
    • 

  • Option B: enqueue with insert(0, item), dequeue with pop(), enqueue shifts every item
    • 

  • Either way, one of the two operations is O(n)
    •

Queue using a linked list: head and tail






    

  • A stack only needed a pointer to the head, a queue needs a pointer to the head and a pointer to the tail
    • 

  • dequeue removes from the head, the same way stack pop does
    • 

  • enqueue adds at the tail: link the current tail to the new node, then move tail to the new node
    • 

  • Removing the tail would mean walking the whole list to find the node before it
    •
